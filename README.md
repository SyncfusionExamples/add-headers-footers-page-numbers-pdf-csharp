# Add Headers, Footers, and Page Numbers to PDFs in C#

The Syncfusion .NET PDF Library enables developers to add headers, footers, and page numbers to PDF documents with precision and flexibility. This guide presents a curated set of samples that demonstrate how to create basic headers and footers, enhance them with images, apply page numbering formats, and customize layout based on page sections or parity.

 Sample name | Description
------|------
[Add Basic Header and Footer to a PDF](https://github.com/SyncfusionExamples/add-headers-footers-page-numbers-pdf-csharp/tree/master/create-pdf-with-header-and-footer) | Demonstrates how to add simple text-based headers and footers to PDF pages. Ideal for adding titles, author names, or document metadata.
 [Enhance Headers and Footers with Images](https://github.com/SyncfusionExamples/add-headers-footers-page-numbers-pdf-csharp/tree/master/header-and-footer-with-images) | Shows how to include logos, watermarks, or other images in headers and footers to improve branding and visual appeal.
[Add Page Numbers in “Page X of Y” Format](https://github.com/SyncfusionExamples/add-headers-footers-page-numbers-pdf-csharp/tree/master/add-page-numbers-in-pdf) | Explains how to insert page numbers in the format “Page X of Y” using C#. This is useful for navigation and printing purposes.
[Customize Headers and Footers for Odd and Even Pages](https://github.com/SyncfusionExamples/add-headers-footers-page-numbers-pdf-csharp/tree/master/headers-and-footer-for-odd-and-even-pages) | Demonstrates how to apply different header and footer layouts for odd and even pages, commonly used in booklets and double-sided printing.
[Section-Based Headers, Footers, and Page Numbers](https://github.com/SyncfusionExamples/add-headers-footers-page-numbers-pdf-csharp/tree/master/section-based-header-and-footer) | Shows how to define headers, footers, and page numbering per section, allowing for distinct formatting across chapters or document parts.
[Add Headers and Footers in an Existing PDF Document](https://github.com/SyncfusionExamples/add-headers-footers-page-numbers-pdf-csharp/tree/master/add-headers-and-footers-to-existing-pdf) | Explains how to modify an existing PDF by adding headers and footers without regenerating the entire document.

## How to run the examples

* Download this project to a location in your disk.
* Open the solution file using Visual Studio.
* Rebuild the solution to install the required NuGet package.
* Run the application.
